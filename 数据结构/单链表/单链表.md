# 单链表

这里的单链表是依赖于两个数组实现，根据y总的源码稍微改了一点点），我们来看一下代码实现

```cpp
//----------------单链表的数组实现---------------
const int N = 100010;

// v[k]存放编号为k的节点数值
// nxt[k]存编号为k的节点的下一个节点编号
int v[N], nxt[N];

// head为头节点编号
// id用于分配节点编号
int head, id;

// 初始化（-1代表指向空）
void init(){
    head= -1, id= 0;
}

// 添加到链表头部（头插法）
void add_to_head(int val){
    v[id]= val; //设置新节点值
    nxt[id]= head; //设置新节点指向
    head= id++; //更新head指针，并给id（可分配编号）+1
}

// 添加到编号为k的节点后
void add_to(int k, int val){
    v[id]= val; //设置新节点值
    nxt[id]= nxt[k]; //设置新节点指向（为编号为k的节点的指向）
    nxt[k]= id++; //把编号为k的节点指向新节点，并给id+1
}

// 删除编号为k的节点的后一个节点
void rmv_after(int k){
    if (nxt[k] == -1) return; // 如果 k节点是最后一个节点就直接返回
    int p_after_k = nxt[k]; // 编号 k节点后一个节点的编号
    nxt[k]= nxt[p_after_k]; // 把 k的指向改为后一个节点的指向
}

```

代码的解释我都写在了注释里面，我觉得这样方便阅读一些😋

但是还是要提一嘴，这种方法的实现中

- **`id`只是用来实现新的节点的编号分配**
- **`nxt[]`数组才是用来维护关系的**

```cpp
struct Node{
    int val; // 对应于 v[]
    Node *next; // 对应于 nxt[]
};
```

上面这个代码应该是最常见的实现了，但是这种方法有一个缺点，就是构建新的节点需要使用关键字`new`—— 这在算法题里面是很影响效率的，所以直接用数组实现是最为理想的😋
