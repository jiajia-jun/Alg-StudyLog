# 栈

其实C++已经实现了栈这个数据结构了，所以我们就讲一下`<stack>`头文件里面的栈如何使用的算鸟😋，想学习模拟栈的可以去看cpp代码

## 引入

```cpp
#include <stack>
using namespace std; 
```

## 声明与初始化

```cpp
stack<这里写数据类型> a；
```

## 主要成员函数

| 函数 | 作用 |
| ------ | ------ |
| `push(x)` | 元素 `x` 入栈（入栈） |
| `pop()` | 弹出**栈顶**元素（无返回值） |
| `top()` | 返回栈顶元素引用（注意是引用，不是拷贝的） |
| `empty()` | 判断栈是否为空 |
| `size()` | 返回栈中元素个数 |

记住上面这些基本上够了😋
