# 双链表

理解了单链表之后，双链表其实简单很多的，不过就是多加了一个指向而已，下面是代码实现

```cpp
const int N= 100010;

// v[k]:编号为 k的节点的值
// l[k]:编号为 k的节点的左侧节点编号
// r[k]:编号为 k的节点的右侧节点编号
// idx: 可分配的节点编号
int v[N], l[N], r[N], idx;

// 初始化，规定左侧哨兵节点编号为 0，右侧为 1
void init(){
    l[1]= 0, r[0]= 1;
    idx= 2;
}

// 向节点 k右侧添加新的节点
void add_r(int k, int val){
    // 新节点信息
    v[idx]= val;
    // 新节点右侧指向 k的右节点 r[k]，左侧指向 k节点
    r[idx]= r[k], l[idx]= k;

    // 原 k节点右侧的 r[k]节点左指向新节点
    l[r[k]]= idx;
    // 原 k节点指向新节点
    r[k]= idx++;

}

// 删除 k节点
void rmv(int k){
    // k节点左侧的 l[k]节点右指向 k节点的右侧 r[k]
    r[l[k]]= r[k];

    // k节点右侧的 r[k]节点左指向 k节点的左侧 l[k]
    l[r[k]]= l[k];
}
```

这里要强调一下一个地方，就是这一段代码：

```cpp
void init(){
    l[1]= 0, r[0]= 1;
    idx= 2;
}
```

编号为`0`的节点和编号为`1`的节点均为**哨兵节点**，目的是**确定双链表的头和尾的**，所以真正存储数据的是**从编号`2`开始的后续节点**

`idx`和单链表作用一样，只作为可分配编号使用的，且不断递增

下面还有一些相关操作，可以看看  

## 相关操作

### 在最左侧插入节点

```cpp
add_r(0, x);
```

### 在最右侧插入节点

```cpp
add_r(l[1], x);
```

### 删除编号k节点

```cpp
rmv(k);
```

### 在编号k节点左侧添加节点

```cpp
add_r(l[k], x);
```

### 在编号k节点右侧添加节点

```cpp
add_r(k,x);
```

### 输出整个双链表

```cpp
for(int i= r[0];i!= 1; i=r[i]){
    cout<< v[i]<< ' ';
}
```
