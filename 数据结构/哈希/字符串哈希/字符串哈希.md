# 字符串哈希

我们先来看一下题目：
> 给定一个长度为 n 的字符串，再给定 m 个询问，每个询问包含四个整数 l1,r1,l2,r2，请你判断 [ l1 , r1 ] 和 [ l2 , r2 ] 这两个区间所包含的字符串子串是否完全相同。  
> 字符串中只包含大小写英文字母和数字。

这是一个字符串匹配的问题，我们之前也接触到过KMP算法，但我们今天引入另一个字符串匹配算法：**字符串哈希**

所谓字符串哈希，就是**把一段特定的字符串，映射为一个特定的值，通过比较这个值，我们就可以得出两个字符串是否相同**

老样子，先看代码实现，再讲核心代码

```cpp
#include<iostream>
#include<string>
using namespace std;

typedef unsigned long long uii;

const int N= 100010;
// P常用 131和 13331这两个经验值
const int P= 131;

// hsh[i]: 记录[1, i]区间的字符串的哈希值
// p[k]: 存储p的 k次幂
uii hsh[N], p[N];

// 求[l, r]字符串的哈希值(l, r>=1): hsh[r]- hsh[l-1]* (p^区间长度)
// 这里要返回 uii
uii get_hash(int l, int r){
    return hsh[r]- hsh[l-1]* p[r-l+1];
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    string s;
    cin>> n>> m;
    cin>> s;

    // 初始化
    // 计算每一段前缀的哈希值和 P的不同次幂
    p[0]= 1; // P^0= 1
    for(int i=1; i<=n; ++i){
        hsh[i]= hsh[i-1]* P+ s[i-1];
        p[i]= p[i-1]* P;
    }

    while(m--){
        int l1, r1, l2, r2;
        cin>> l1>> r1>> l2>> r2;
        // 比较两个区间的哈希值是否相同，哈希值相同就代表字符串相同
        if(get_hash(l1, r1)== get_hash(l2, r2)){
            cout<<"Yes\n";
        }
        else cout<<"No\n";
    }
}
```

## 核心代码讲解

### 原理

我们先来讲讲字符串哈希的实现原理，
字符串哈希的最重要的地方就是**如何才可以得到唯一特定的哈希值**，下面是计算过程：

- 第一步：映射  
把字符串里面的不同字符先映射成不同的数字（代码里的体现就是 `+s[i]`，直接使用ASCII值）

- 第二步：定基 P  
这里的 P 相当于进制，按照经验值取`131`或者`13331`（代码里面取131）

- 第三步：计算hash
哈希的计算公式是（`s`是字符串，从下标 0开始）:

```text
 H(n) = (s[0]* P^(n-1)+ s[1]* P^(n-2)......+s[n-1]* (P^0) ) mod Q
 ```

其中，`Q`是一个大数，我们取**2^64**，这样使用 unsigned long long的时候，溢出的部分就是取模的结果了，所以代码里面就没有使用宏定义`Q`了😋

### 代码实现

理解了hash值如何得到的后，我们来看一下代码实现  
首先，我们先定义两个数组  

```cpp
typedef unsigned long long uii;
// hsh[i]: 记录[1, i]区间的字符串的哈希值
// p[k]: 存储p的 k次幂
uii hsh[N], p[N];
```

其中，`hsh[i]`记录 **[1, i]区间的字符串的哈希值**，`p[k]`存储 **P的 k次幂**

然后我们对这两个数组进行初始化，依据前面的 hash计算公式会更好理解下面这个代码

```cpp
// 初始化
// 计算每一段前缀的哈希值和 P的不同次幂
p[0]= 1; // P^0= 1
for(int i=1; i<=n; ++i){
    hsh[i]= hsh[i-1]* P+ s[i-1];
    p[i]= p[i-1]* P;
}
```

最后，我们再来看一下字符哈希的一个最重要的部分，就是所谓的得到 [l,r] 区间的 hash值

```cpp
// 这里要返回 uii
uii get_hash(int l, int r){
    return hsh[r]- hsh[l-1]* p[r-l+1];
}
```

这里有一个求 [l, r] 字符串的 hash值公式(l, r>=1)：

```text
hsh[r]- hsh[l-1]* (p^区间长度)
```

这个公式如果不想推导的话，记住就好了，其实和前缀和是有点像的，不过就是多考虑了一个进制情况
