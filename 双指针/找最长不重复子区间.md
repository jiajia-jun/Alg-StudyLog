# 双指针

我们来看一个例题：
>给定一个长度为 n 的整数序列，请找出最长的不包含重复的数的连续区间，输出它的长度。  

题目采用暴力解法确实可以，你可以循环遍历每一个可能的子区间，但是时间复杂度就来到了O(n²)  
所以，这里我们使用**双指针**来维护这一段区间，下面是实现代码：  

```cpp
#include<iostream>
#include<map>

using namespace std;

const int N=100010;

map<int, int> mp;
int a[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin>> n;
    for(int i=0; i<n; ++i) cin>> a[i];

//--------------------核心区分割线---------------------
    // 这里有点晦涩难懂
    int re=0;
    for(int i=0, j=0; i<n; ++i){
        mp[a[i]]++;
        while(j<i && mp[a[i]]>1){
            mp[a[j]]--;
            j++;
        }
        re= max(re,i-j+1);
    }
//--------------------核心区分割线---------------------

    cout<< re <<' ';
}
```

这个代码最难懂的地方就是下面这个部分（我当时也花了老大劲才搞懂，然后稍微改了一下y总的代码，增加了一点可读性）：

```cpp
int re=0; // 初始化结果为0

        mp[a[j]]--;
        j++;
    }

```

现在，我们来讲解一下这个部分

---

## 核心代码讲解

先来说明一下下面两个数据结构的作用

```cpp
map<int, int> mp;
int a[N];
```

- `map<int, int> mp` 用来记录每一个数字出现的次数（其实用数组也可以实现的）
- `int a[N]`用于存放原数组

在整个核心代码运行期间，`i`为快指针， `j` 为慢指针

```cpp
for(int i=0, j=0; i<n; ++i){
    mp[a[i]]++;
}
```

这里是`i`快指针不断向右拓展右边界，并记录对应数字的出现次数  

但是当扩展完区间右端点之后，有可能这个数字会出现重复，下面这个while循环就是用来去除重复  
去重的办法就是，就是收缩区间左端点，同时收缩时要保证`j`是小于`i`的（像毛毛虫一样），反正我们要得到是最大的子区间的长度

```cpp
// 循环条件：j在i左侧（j<i）且i所在的数字出现重复了（mp[a[i]]>1）
while(j<i && mp[a[i]]>1){
        mp[a[j]]--; //要收缩左边界，区间内j对应的数字出现次数就要-1
        j++;// j指针移动
    }
```

最后，每一次都记录下符合条件的区间最大长度

```cpp
re= max(re,i-j+1);
```

---

关于这个题的双指针应用差不多就这样，自己拿一组数去试试会更好，比如 `1 1 2 1 3 3 5 6 7 6 8 9`，结果是 4
