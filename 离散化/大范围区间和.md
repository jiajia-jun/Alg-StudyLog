# 大范围区间和

题目：  

```text
假定有一个无限长的数轴，数轴上每个坐标上的数都是 0。
现在，我们首先进行 n 次操作，每次操作将某一位置 x 上的数加 c。
接下来，进行 m 次询问，每个询问包含两个整数 l 和 r，你需要求出在区间 [l,r] 之间的所有数的和

第一行包含两个整数 n 和 m
接下来 n 行，每行包含两个整数 x 和 c
再接下来 m 行，每行包含两个整数 l 和 r

−10^9 ≤ x ≤ 10^9,
1 ≤ n, m ≤ 10^5,
−10^9 ≤ l ≤ r ≤ 10^9,
−10000 ≤ c ≤ 10000

```

这个题乍一看求区间和，想到用前缀和  
但是仔细一看，给定的位置范围特别大，但是真正有值的位置特别少  
所以，我们就要压缩数轴  
>**当问题的范围很大，但是能够用上的数据很少的时候，就需要压缩大区间到一个小范围的有效区间**

这就是离散化的含义  

下面是代码实现（参考Acwing的，我觉得这个题可以直接用map更加好理解的，后续我写一个）

```cpp
#include<iostream>
#include<algorithm>
#include<vector>

using namespace std;

const int N = 300010;

typedef pair<int, int> pii;

// list的作用：
// 1.存储所有出现过的原始坐标（包括修改位置 x 和询问端点 l, r），用于离散化
// 2.存放离散化后的相对位置情况
vector<int> list;

// a 用来存放离散化后的相对索引下对应的值（1-base）
// s 用来存放前缀和（1-base）
int a[N], s[N];

// origin 存放修改操作：{修改位置x, 值c}
// query  存放询问操作：{l, r}（均为原始坐标）
vector<pii> origin, query;


int main(){
    int n, m;
    cin>> n>> m;

    // 读入修改位置和值
    for(int i=0; i<n; ++i){
        int x, c;
        cin>> x>> c;

        origin.push_back({x, c});

        list.push_back(x);
    }

    // 读入查询区间
    for(int i=0; i<m; ++i){
        int l, r;
        cin>> l>> r;
        query.push_back({l, r});

        // list存入询问区间的左右端点，为离散化压缩做准备（作用1）
        list.push_back(l);
        list.push_back(r);
    }

    // list存放离散化后的相对位置情况（作用2）
    sort(list.begin(), list.end()); // 排序得到相对位置
    list.erase(unique(list.begin(), list.end()), list.end()); // 去重


    for(int i=0; i<n; ++i){
        //下面两行是为了把有值的位置录入a中
        auto t= lower_bound(list.begin(), list.end(), origin[i].first); 
        a[t-list.begin()+1] += origin[i].second;// 从1开始可以省去前缀和的边界问题
    }

    // 对a[]进行前缀和
    for(int i=1; i<= list.size() ; ++i){
        s[i] = s[i-1] + a[i];
    }

    // 计算离散化后的等效索引
    for(auto &q:query){
        // 这里是获取原来询问的坐标
        int origin_l = q.first;
        int origin_r = q.second;
        
        // 这里是查找原来询问的坐标离散化之后，在list中所对应的下标（注意是 1-base）
        // 由于前缀和数组从下标 1开始，所以这里要加上 1
        int l= lower_bound(list.begin(), list.end(), origin_l) - list.begin()+1;
        int r= lower_bound(list.begin(), list.end(), origin_r) - list.begin()+1;
        cout<< s[r]- s[l-1]<< '\n';
    }
    return 0;
}
```

这一题的关键还是要意识到，我们要用到的是**数据的相对位置，而不是绝对位置**
