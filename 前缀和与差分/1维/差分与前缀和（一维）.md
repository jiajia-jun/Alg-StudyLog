# 前缀和与差分（一维）

前缀和和差分其实更像是一种思想

## 前缀和

先来讲前缀和。所谓前缀和，就是**前 i 个数的和**，用一个数组 `s` 来记录：`s[i] = a[1]+a[2]+...+a[i]`（这很像高中数学数列的前n项的和 ~~其实就是~~）  

下面一个前缀和的应用：
>输入一个长度为 n 的整数序列  
>接下来再输入 m 个询问，每个询问输入一对 l,r 区间（l，r>=1）  
>对于每个询问，输出原序列中从第 l 个数到第 r 个数的和

下面是实现代码（为了方便看懂，我使用了两个数组，实际上这个问题只要一个就好了）

```cpp
#include<iostream>

using namespace std;

const int N=1000;

int a[N],s[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    //输入n个数，查询m次索引区间[l,r]的和(l>=0,r>=0)
    int n, m;
    cin>>n >> m;
    for(int i=1; i<=n; ++i) cin>>a[i];

    //前缀和
    for(int i=1; i<=n; ++i){
        s[i]= s[i-1]+ a[i];
        //也可以直接采用一个数组就实现前缀和 a[i]= a[i-1]+ a[i]; 前提是原数组不再被使用了
    }

    while(m--){
        int l, r; //l，r均为一段1-base区间
        cin>>l >>r;
        cout<< s[r]-s[l-1] << '\n';
    }
}
```

依旧解释核心部分

---

### 核心代码讲解

```cpp
for(int i=1; i<=n; ++i){//这里就是在实现前缀和
    s[i]= s[i-1]+ a[i];
} 
```

`s[i]`的含义就是**前i个数的和**（前缀和）

这里有个**建议**：下标从 1 开始存储数组（1-base），这样 `s[0]` 自然就是 0，查询 `[1,r]` 的时候当 `l = 1` 的时候不会越界也不用特判边界

---

```cpp
cout<< s[r]- s[l-1];
```

前缀和最经典的应用：**O(1) 查询区间和**。`s[r]` 是前 r 个数的和，`s[l-1]` 是前 l-1 个数的和，两者的差`s[r]-s[l-1]` 也就是中间区间 `[l,r]` 这段的和就出来了

举个例子，`a=[1,2,3,4,5]`：

```text
s[1]=1, s[2]=3, s[3]=6, s[4]=10, s[5]=15
```

查询 `[2,4]` 的和：`s[4]-s[1]=10-1=9`，即 `2+3+4=9`

## 差分

接下来是差分。差分就是前缀和的**逆运算**：前缀和是"前n个累加"，差分是"两两做差"

差分数组，原数组，前缀和数组有一个很特别的关系

```text

            差分               差分
差分数组 <---------- |原数组 <---------- 前缀和数组
        ---------->         ---------->
            前缀和            前缀和

```

下面便有一个体现两者关系的题目：  

>输入一个长度为 n的整数序列  
>接下来输入 m 个操作，每个操作包含三个整数 l, r, c，表示将序列中 [l,r] 之间的每个数加上 c  
>请你输出进行完所有操作后的序列。

这个题传统的暴力确实可以解，但是时间复杂度就不乐观了，下面来看怎么用差分实现：

```cpp
#include<iostream>

using namespace std;

const int N= 100010;
int a[N],d[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,m;
    cin>> n>> m;
    for(int i=1; i<=n; ++i) cin>> a[i];

//--------------------核心区分割线---------------------
    // 差分数组
    for(int i=1; i<=n; ++i){
        d[i]= a[i]-a[i-1]; 
    }

    while(m--){
        int l, r, c;
        cin>>l >>r >>c;
        d[l]+= c;
        d[r+1]-=c;
    }
    for(int i=1; i<=n; ++i){
        d[i]+=d[i-1]; // 进行一次前缀和，回到修改后的数组
        cout<< d[i]<<' ';
    }
//--------------------核心区分割线---------------------
    return 0;
}
```

我们来解释一下核心区域

---

### 核心代码

```cpp
d[i]= a[i]- a[i-1];
```

这里是差分数组的定义：相邻两个数两两作差，`a[i]- a[i-1]`

---

而 差分+前缀和 可以把 **"区间修改"** 变成 **"单点修改"**，这也是差分+前缀和的很常见的一个应用：  

先对差分数组的如下地方进行操作

```cpp
d[l] += c;   // 在 l 处加上c
d[r+1] -= c; // 在 r+1 处减去c，在计算前缀和的时候可以防止对 r 位置后的数字造成影响
```

然后，再进行一次前缀和的操作：  

```cpp
for(int i=1; i<=n; ++i){
    d[i] += d[i-1]; // 进行一次前缀和，回到修改后的数组
    cout<< d[i]<<' ';
}
```

这样得到的结果就是对特定区间操作后的原数组了，就不用来一次嵌套for循环了

---
为什么？直接举例子：  
 `a=[a1, a2, a3, a4, a5]`，想要给 [a2,a4] 加上c  

- 第一步，得到差分数组  
`d=[a1, a2-a1, a3-a2, a4-a3, a5-a4]`
- 第二步`d[l] += c;`  `d[r+1] -= c;`得到  
`d=[a1, a2-a1+c, a3-a2+c, a4-a3+c, a5-a4-c]`
- 最后，按照前缀和操作，最后结果为：  
`d=[a1, a2+c, a3+c, a4+c, a5]`
