# 差分与前缀和（二维）

对于二维前缀和与差分，我打算试试讲一下他们的几何意义

## 二维前缀和

我们先来看一个问题  
> 给出一个点阵，需要你计算某个以 (x1, y1) 为左上角，(x2, y2)为右下角的点阵区域的和  

这个问题就是二维前缀和的应用

我们先来给出二维前缀和的几何意义（很重要）：
>>**`s[i][j]`代表着这个点与坐标原点围成的矩形区域内（包含边界）所有点的权重之和**

下面我们来看代码实现：

```cpp
#include<iostream>
using namespace std;

const int N= 1010;
int a[N][N]={0}, s[N][N]={0};

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin>>n >>m>> q;

    //从 1 开始存可以免去繁杂的边界问题
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            cin>>a[i][j];
        }
    }

//--------------------核心区分割线---------------------    
    // 前缀和
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            // 注意，这里是点阵，所以是这样计算的（画一个格子点图会更加好理解的😋）
            s[i][j]= s[i-1][j]+ s[i][j-1]+ a[i][j]-s[i-1][j-1];
        }
    }


    // 子矩阵的和
    while(q--){
        // 均为1-base下的索引坐标
        int x1, y1, x2, y2;
        cin>> x1>> y1>> x2>> y2;
        cout<< s[x2][y2]- s[x1-1][y2]- s[x2][y1-1]+ s[x1-1][y1-1]<<'\n';
    }
//--------------------核心区分割线---------------------
    
    return 0;
}
```

---

### 核心代码讲解

前缀和一共有两个公式：

- `s[i][j]= s[i-1][j]+ s[i][j-1]+ a[i][j]-s[i-1][j-1]`
- `s[x2][y2]- s[x1-1][y2]- s[x2][y1-1]+ s[x1-1][y1-1]`

第一个公式用来计算`s[i][j]`的值，还记的这个的几何意义吗？**`s[i][j]`代表着这个点与坐标原点围成的区域内（包含边界）所有点的数值之和**

第二个公式用来计算以 (x1, y1) 为左上角，(x2, y2)为右下角的点阵区域的和

这两个公式如果自己画一个点阵图，根据`s[i][j]`的含义就可以很快理解了（如果有机会，我以后会加上的😭）

## 差分

说实话，差分这里不方便单独拿出来讲，我觉得配合前缀和一起讲更好  
二维差分+前缀和主要解决的是这样一个问题：
**给二维点阵某个区域的点全部加上一个数**  

下面我们来看看代码实现：

```cpp
#include<iostream>
using namespace std;

const int N= 10010;
int a[N][N], d[N][N];

// 配合前缀和，可以让修改可以形成一个平面范围的影响
// 你可以自己画一个点阵，左上角为原点
// 然后这段代码配合最后的前缀和的几何意义就是：
// 以坐标为左上角的点的矩形，区域内的所有点都加上c
void dif(int x1, int y1, int x2, int y2, int c){
    d[x1][y1]+= c;
    d[x1][y2+1]-= c;
    d[x2+1][y1]-= c;
    d[x2+1][y2+1]+= c;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin>>n >>m>> q;

    // 从 1 开始存可以免去繁杂的边界问题
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            cin>>a[i][j];
        }
    }
    
//--------------------核心区分割线---------------------
    // 这里并不是直接采用公式构造，要注意了
    // 这种写法和使用公式构造差分数组的效果是一样的
    // 差分公式：d[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            dif(i, j, i, j, a[i][j]); 
        }
    }

    // 指定子矩阵区域加上c
    while(q--){
        int x1,y1,x2,y2,c;
        cin>> x1>> y1>> x2>> y2 >>c;
        dif(x1, y1, x2, y2, c);
    }
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            d[i][j]+= d[i-1][j]+ d[i][j-1]- d[i-1][j-1]; // 前缀和
        }
    }
//--------------------核心区分割线---------------------
 
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            cout<< d[i][j] <<' ';
        }
        cout<<'\n';
    }
}
```

---

### 核心代码

二维差分公式是这个：

- `d[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]`

但是，这里我们使用了另外一个办法来实现差分数组的创建：  
先定义一个`dif`函数

```cpp
void dif(int x1, int y1, int x2, int y2, int c){
    d[x1][y1]+= c;
    d[x1][y2+1]-= c;
    d[x2+1][y1]-= c;
    d[x2+1][y2+1]+= c;
}
```

然后这样子写：

```cpp
// 这里并不是直接采用公式构造，要注意了
    // 这种写法和使用公式构造差分数组的效果是一样的
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            dif(i, j, i, j, a[i][j]); 
        }
    }
```

这样子得到的差分数组和使用公式构造是一个效果的

**可是我们为什么要这样写？**原因：

这个函数配合前缀和，**可以让修改可以形成一个平面范围的影响**  
你可以自己画一个点阵，左上角为原点，然后这段代码配合最后的前缀和的几何意义就是：
>>以坐标为左上角的点的矩形，区域内的所有点都加上c

这一点很重要，直接影响到我们后续理解，下面这个代码就是对这个意义的应用：

```cpp
while(q--){
        int x1,y1,x2,y2,c;
        cin>> x1>> y1>> x2>> y2 >>c;
        dif(x1, y1, x2, y2, c);
    }
    for(int i=1;i<=n; ++i){
        for(int j=1; j<=m; ++j){
            d[i][j]+= d[i-1][j]+ d[i][j-1]- d[i-1][j-1]; // 前缀和
        }
    }
```
